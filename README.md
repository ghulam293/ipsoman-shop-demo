# IPS Oman Books & Uniforms

A responsive, front-end demo of a grade-specific school books and uniforms
catalogue for IPS Oman.

## Run locally

Open `index.html` in a browser, or serve this folder using Python:

```powershell
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deploy to Vercel

Import the GitHub repository into Vercel and deploy it as a static site. The
project has no build step; the site entry point is `index.html`.

## Demo data

Sample products, OMR prices, and seller names are for demonstration only. They
are not live school approvals, offers, or supplier contact details. Verify all
catalogue items, prices, and seller information with the school before
publication. Purchases and payments take place with sellers outside this app.
